# Diseño

`mockup-inicio.html` es una copia literal de la maqueta aprobada de la pantalla de inicio
(https://claude.ai/artifact/HNWPRP3ENBs9sL5xKvKnX4), guardada el 2026-11-12.

Es una referencia para leer, no una página para abrir en el navegador: usa el formato del editor de
diseño de claude.ai (`<x-dc>`, `{{accent}}`, `support.js`), así que fuera de él no se muestra bien.
Lo que sirve de ella: la estructura de la pantalla, los estilos en línea y el script del fondo de
nieve.

Si la maqueta cambia en claude.ai, vuelve a copiarla aquí.
